프로젝트명: 심플 게시판 프로토타입

기술 스택

  • HTML5: 웹 페이지의 기본 구조를 정의합니다.
  • TypeScript: 자바스크립트에 타입을 추가하여 안정적이고 유지보수가 쉬운 코드를 작성합니다. 브라우저용은 컴파일하여 JS로 사용합니다.
  • CSS3: 웹 페이지의 시각적 디자인과 레이아웃을 담당합니다.
  • Node.js & Express: 서버 측 로직을 처리하고 REST API를 구축합니다.
  • Neon (PostgreSQL): 클라우드 기반의 관계형 데이터베이스로, 데이터를 안전하게 저장합니다.

시각적 디자인 샘플 (선택 필요)

1. 미니멀 화이트
깔끔한 흰색 배경에 검정색 텍스트, 얇은 선을 사용한 현대적 디자인.
2. 소프트 파스텔
연한 파란색과 분홍색 톤을 사용하여 부드럽고 친근한 느낌의 디자인.
3. 다크 모던 (기본 테마 아님)
심플한 그레이톤 배경에 밝은 포인트 컬러를 사용한 가독성 중심 디자인. (요구사항 반영)
4. 클래식 보드
기존 커뮤니티 게시판과 유사한 익숙한 테이블 형태의 레이아웃.
5. 카드형 레이아웃
게시글을 그리드 형태의 카드로 배치하여 시각적 흥미를 유도하는 디자인.

데이터베이스 설계

테이블 목록

  • users: 사용자 계정 정보
  • posts: 게시글 정보
  • comments: 댓글 정보
  • likes: 게시글 추천 정보 (중복 방지)

SQL Create 문

CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE comments (
    id SERIAL PRIMARY KEY,
    post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE likes (
    id SERIAL PRIMARY KEY,
    post_id INTEGER REFERENCES posts(id) ON DELETE CASCADE,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    UNIQUE(post_id, user_id)
);
